# Digital Arts

Brand website and discovery platform for digital art and printable products.

## Product direction

Digital Arts is designed as more than an Etsy storefront. The website should help customers discover the right digital product, build organic search traffic, capture freebie/email leads, and support future direct sales.

## MVP

1. Home
2. Shop
3. Product detail
4. Collections
5. Freebies
6. Activity Finder

## Planned stack

- Next.js
- TypeScript
- Vercel
- Supabase
- GitHub

## Roadmap

- Phase 1: Brand website + product discovery
- Phase 2: Search, collections, filters and SEO
- Phase 3: Freebies + email funnel
- Phase 4: Activity Finder + recommendations
- Phase 5: Direct checkout + customer library
- Phase 6: Membership / personalized recommendations
